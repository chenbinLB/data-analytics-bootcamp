# 一键安装教程(小白版,5 步走通)

> 这份教程是写给**完全没装过 Python 的小白**看的。
> 跟着做,15 分钟搞定。

---

## 步骤 0:确认你的电脑是 Windows / Mac

- **Windows**:看左下角开始菜单,有"Windows 标志"= Windows
- **Mac**:屏幕左上角有  图标 = Mac

下面分两个版本,**你用哪个就跳到对应章节**。

---

# Windows 版(Windows 10 / 11)

## Step 1:下载 Python(2 分钟)

1. 打开浏览器,访问: **https://www.python.org/downloads/**
2. 点击最大的黄色按钮 "Download Python 3.11.x"
3. 下载得到一个 `.exe` 文件(比如 `python-3.11.9-amd64.exe`)

**✅ 验证**:双击这个 .exe 文件,看到安装界面 = 下载成功

## Step 2:安装 Python(3 分钟)

⚠️ **这一步非常关键,90% 的小白错在这里!**

1. 双击下载的 `.exe` 文件
2. **🚨 第一个界面:勾选 "Add Python to PATH"** ← 这个必须勾上!
3. 点击 "Install Now"
4. 等待 1-2 分钟,看到 "Setup was successful" = 安装成功

**图示说明**(你应该看到的画面):
```
┌──────────────────────────────────────┐
│  Install Python 3.11.9               │
│                                      │
│  ☑ Add python.exe to PATH  ← 这个!  │
│                                      │
│  [Install Now]                       │
└──────────────────────────────────────┘
```

## Step 3:验证 Python 装好了(30 秒)

1. 按 `Win + R` 键,输入 `cmd`,回车
2. 黑色窗口里输入:
   ```
   python --version
   ```
3. 如果看到 `Python 3.11.9` 之类的 = 成功
4. 如果提示 "不是内部命令" = 回到 Step 2 重装,**一定勾 PATH**

**✅ 验证**:看到 Python 版本号 = 通过

## Step 4:解压课程包(1 分钟)

1. 下载我发给你的网盘链接里的 `data-analytics-bootcamp-49.zip`
2. **右键** -> "解压到当前文件夹"(需要装 7-Zip 或 WinRAR)
3. 解压后得到一个文件夹,比如 `D:\data-analytics-bootcamp\`

**推荐放哪里**:
- ✅ `D:\data-analytics-bootcamp\`
- ✅ `C:\Users\你的用户名\Desktop\data-analytics-bootcamp\`
- ❌ 不要放桌面再套一层文件夹(容易路径过深)

## Step 5:运行一键安装(3-5 分钟)

1. 打开解压后的文件夹
2. 找到 **`setup_env.py`** 文件
3. **右键** -> "在终端中打开" 或 "PowerShell 中打开"
   - 如果没有这个选项:在文件夹空白处 **Shift + 右键** -> "在此处打开 PowerShell 窗口"
4. 在打开的窗口里输入:
   ```
   python setup_env.py
   ```
5. 按回车,等待 2-3 分钟,看到 "依赖安装完成" = 成功
6. 浏览器会自动打开 Jupyter Lab 界面
7. 左侧文件树里,双击 `module_01_sql/01_basics_review.ipynb`
8. 点击"运行"按钮(或按 Shift + Enter),看到代码输出 = 一切就绪 🎉

**🚨 如果出错**:看下面"常见问题"章节

# Mac 版(macOS 12+)

## Step 1:检查有没有 Python(1 分钟)

1. 按 `Cmd + 空格`,输入 `terminal`,回车
2. 输入:
   ```
   python3 --version
   ```
3. 如果看到 `Python 3.9.x` 或更高 = 已经有,跳到 Step 2
4. 如果提示 "command not found" = 需要装

## Step 2:安装 Python(2 分钟)

**方式 A:用 Homebrew(推荐)**
```bash
# 1. 先装 Homebrew(已经装过跳过)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 装 Python
brew install python@3.11
```

**方式 B:用官方安装包**
1. 访问 https://www.python.org/downloads/macos/
2. 下载 "python-3.11.9-macos11.pkg"
3. 双击安装,一路点继续

## Step 3:解压课程包(1 分钟)

1. 下载网盘里的 `data-analytics-bootcamp-49.zip`
2. **双击** 自动解压
3. 把解压后的文件夹移到 `~/Documents/` 或 `~/Desktop/`

## Step 4:运行一键安装(3-5 分钟)

1. 打开终端(Terminal)
2. 进入课程目录:
   ```
   cd ~/Documents/data-analytics-bootcamp
   ```
3. 运行:
   ```
   python3 setup_env.py
   ```
4. 等待 2-3 分钟,看到 "依赖安装完成" = 成功
5. 浏览器自动打开 Jupyter Lab
6. 双击 `module_01_sql/01_basics_review.ipynb`
7. 按 Shift + Enter 运行第一个 cell,看到输出 = 一切就绪 🎉

# 常见问题(小白一定会卡的地方)

## Q1: 提示 "python 不是内部命令"
**A**:90% 是 Step 2 没勾 "Add to PATH"。卸载重装,**第一步就勾上**。

**怎么卸载 Python**:
- Windows: 设置 -> 应用 -> 搜 "Python" -> 卸载
- 重装时**第一步**勾上 "Add Python to PATH"

## Q2: pip install 一片红 SSL 错误
**A**:网络问题(尤其公司网/校园网有限制)。
```bash
# 用国内镜像源
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

## Q3: 安装太慢/卡住
**A**:1) 换镜像源(上面 Q2); 2) 关掉 VPN; 3) 关掉杀毒软件

## Q4: 提示 "Microsoft Visual C++ 14.0 required"
**A**:极少数包需要编译。**99% 情况下你用不到**,先跳过。
如果真碰到了:https://visualstudio.microsoft.com/visual-cpp-build-tools/

## Q5: 浏览器没自动打开 Jupyter
**A**:1) 看终端最后一行有没有 "http://localhost:8888" 之类的地址
2) 手动复制到浏览器
3) 或者在终端输入: `jupyter lab`

## Q6: 数据文件 26MB 太大,下载慢
**A**:网盘下载会快一些。如果实在慢,先学 W1 SQL,这一周不用数据。

## Q7: Mac 提示 "无法打开,因为它来自身份不明的开发者"
**A**:系统设置 -> 隐私与安全性 -> 仍要打开

## Q8: 我真的卡住了,联系谁?
**A**:微信群答疑(下单后会被拉进群)
