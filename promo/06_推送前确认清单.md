## ⚠️ 推送时常见错误

### 错误 1:Authentication failed
- 解决:用 GitHub Desktop 推送,或配置 SSH key
- 看 promo/05_GitHub推送操作手册.md 第 3 步

### 错误 2:Updates were rejected
```bash
# 解决:先拉再推
git pull origin main --allow-unrelated-histories
git push -u origin main
```

### 错误 3:文件太大 (>100MB)
- 当前项目应该都 < 100MB
- 如果 data/ecommerce.db 太大,看 .gitignore,它已被忽略
