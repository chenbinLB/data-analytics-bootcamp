## 📊 课程内容总览

### W0 小白预备周
- 1 个 notebook,6 cells,3-4 小时学完
- 装好环境 / 跑通第一个程序 / 知道 4 周要学啥
- 20 个 FAQ 应对小白卡点

### W1 SQL 大厂真题
- 4 个 notebook,93 cells
- 基础 + JOIN + 子查询(快速过)
- 窗口函数全套(核心重点)
- CTE + 留存/漏斗/连续登录(业务真题)
- Hive SQL 差异 + 性能优化

### W2 Python 数据处理
- 5 个 notebook,56 cells
- NumPy 核心
- Pandas 基础
- 数据清洗
- 时间序列
- 可视化(Matplotlib + Plotly)

### W3 统计 + A/B + 业务
- 3 个 notebook,20 cells
- 统计学基础(描述性 / 推断性)
- A/B 测试完整流程(样本量 / SRM / 显著性)
- 业务能力(指标体系 / 异动归因 / 5 段式报告)

### W4 实战 + 求职
- 2 个 notebook,11 cells
- 完整电商端到端项目(简历杀手项目)
- AI 协同 + 简历模板 + 面试题 + 求职清单
